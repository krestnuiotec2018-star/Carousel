## ПАЙПЛАЙН ВЫПОЛНЕНИЯ

### ШАГ 1 — АНАЛИЗ ТЕМЫ И СТРУКТУРА

Самостоятельно разбей тему на 5–7 слайдов по этой логике:

| Слайд | Тип | Назначение |
|-------|-----|-----------|
| 1 | HOOK (Заголовок) | Цепляющий заголовок + подзаголовок. Должен останавливать скролл. |
| 2–5 | CONTENT (Контент) | Конкретные факты, советы, инсайты. Один слайд = одна мысль. |
| 6 | SUMMARY (Итог) | Краткий вывод или главный тезис. |
| 7 | CTA (Призыв к действию) | Подписка / сохранить / поделиться / комментарий. |

**Правила копирайтинга для каждого слайда:**
- Заголовок слайда: максимум 6–8 слов, без воды.
- Основной текст: 2–4 коротких пункта ИЛИ 1–2 предложения. Не более 120 символов на блок текста.
- Используй цифры, факты, конкретику — абстракции запрещены.
- Тон: уверенный, экспертный, без канцеляризмов.
- Язык: соответствует языку темы (русская тема → русский текст).

#### 4.2 АВТОПОДБОР РАЗМЕРА ШРИФТА

Скрипт ОБЯЗАН содержать функцию `fit_text_to_box()`:

```python
def fit_text_to_box(draw, text, font_path, max_width, max_height, 
                    size_max=90, size_min=18):
    """
    Итеративно уменьшает размер шрифта от size_max до size_min,
    пока текст с переносами не влезет в max_width x max_height.
    Возвращает (font_object, wrapped_lines).
    """
    for size in range(size_max, size_min - 1, -2):
        font = ImageFont.truetype(font_path, size)
        lines = wrap_text(draw, text, font, max_width)
        total_height = sum(
            draw.textbbox((0, 0), line, font=font)[3] for line in lines
        ) * LINE_SPACING
        if total_height <= max_height:
            return font, lines
    font = ImageFont.truetype(font_path, size_min)
    return font, wrap_text(draw, text, font, max_width)
```

#### 4.3 СТРУКТУРА КАЖДОГО СЛАЙДА

Функция `render_slide(slide_data, slide_num, total_slides, font_regular, font_bold)`:

**Слайд типа HOOK:**
- Центрированный заголовок: жирный шрифт, размер 60–90px, вертикальный центр холста
- Подзаголовок: regular, 28–36px, под заголовком с отступом 40px
- Декоративная линия: 4px, цвет ACCENT_COLOR, ширина 200px, между заголовком и подзаголовком
- Номер слайда: нижний правый угол, SLIDE_NUM_COLOR, 24px

**Слайд типа CONTENT:**
- Заголовок секции: bold, ACCENT_COLOR, 36–48px, верхняя зона (Y: PADDING)
- Разделитель: тонкая линия 2px, PRIMARY_COLOR, от PADDING до CANVAS_W - PADDING
- Основной текст / буллеты: regular, PRIMARY_COLOR, 28–42px, средняя зона
- Для буллетов: символ "▸" перед каждым пунктом, отступ 30px
- Номер слайда: нижний правый угол

**Слайд типа SUMMARY:**
- Аналогично CONTENT, но заголовок — PRIMARY_COLOR, размер крупнее
- Текст центрируется вертикально в нижней половине холста

**Слайд типа CTA:**
- Крупный текст призыва: bold, PRIMARY_COLOR, центр холста
- Иконка или символ действия: ↓ / ♥ / ✦ в ACCENT_COLOR, 80px, над текстом
- Дескриптор аккаунта (если передан): MUTED_COLOR, 24px, нижний центр

### ШАГ 5 — ЗАПУСК СКРИПТА

После создания `carousel_generator.py` — немедленно выполни:

```bash
python3 carousel_generator.py
```

**Обработка ошибок:**
- Если `ModuleNotFoundError: PIL` → выполни `pip install Pillow` и повтори
- Если шрифт не найден → fallback на `ImageFont.load_default()`, предупреди пользователя
- Если ошибка в тексте → выведи traceback и исправь скрипт без запроса подтверждения
- Максимум 3 попытки автоисправления, затем — сообщение об ошибке

## ДОПОЛНИТЕЛЬНЫЕ КОМАНДЫ

| Команда | Действие |
|---------|---------|
| `Пересоздай слайд 3` | Регенерирует только третий слайд с новым контентом |
| `Измени тон на [весёлый/серьёзный/дерзкий]` | Переписывает тексты в нужном тоне и пересоздаёт все слайды |
| `Добавь аккаунт @username` | Добавляет подпись аккаунта на все слайды и пересоздаёт |
| `Смени палитру на [название]` | Меняет цветовую схему (предложи 3 варианта на выбор) |
| `Экспортируй тексты` | Выводит все тексты слайдов в Markdown-формате |
